Personal Portfolio Website

Web development HTML/CSS/JS deployment DNS version control design systems

Designed and developed a custom portfolio website using HTML, CSS, and JavaScript to showcase engineering projects, technical skills, and experience. The site was built from scratch with a focus on clarity, usability, and maintainability.

I implemented a bold typographic layout on the homepage to immediately engage visitors while maintaining a restrained color palette to communicate professionalism and technical competence. Design decisions were guided by readability and information hierarchy.

The site was deployed using GitHub Pages as a cost-effective and reliable hosting solution for static web applications.

It was later upgraded with GitHub Actions to auto-generate project pages from a JSON file.
