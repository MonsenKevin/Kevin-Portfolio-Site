AI-Powered Vision Assistance Prototype

Embedded systems Python Gemini API AI-assisted development hardware integration testing

Problem: Visually impaired users lack affordable, real-time assistive devices that can identify hazards and provide immediate audio feedback.

Approach: Built a wearable prototype using Raspberry Pi with camera module, ultrasonic sensors, and a speaker. Integrated the Gemini API for vision inference and wrote processing logic in Python. Used GitHub Copilot throughout to maintain code quality during a tight academic sprint.

Outcome: Functional prototype achieving 25ms response time and 99% accuracy in controlled testing. Presented to course evaluators as a complete hardware-software system.
