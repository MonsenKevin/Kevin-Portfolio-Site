Network engineering Ubiquiti/UniFi VLANs documentation troubleshooting

Diagnosed recurring wireless network failures caused by a degrading all-in-one consumer router. After evaluating replacement options, I recommended migrating to a Ubiquiti-based network to improve reliability, visibility, and configuration control.

I assisted with the installation and configuration of Ubiquiti networking hardware, including access points and switching infrastructure. After deployment, I created a detailed network diagram documenting device connections and switch port assignments to improve long-term maintainability and troubleshooting.

Since the migration, the network has operated reliably with no reported connectivity issues.
