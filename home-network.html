Home Network Infrastructure Upgrade

Personal Project · April 2025

Network engineering Ubiquiti/UniFi VLANs documentation troubleshooting

Problem: Persistent wireless failures and an unsegmented flat network in a busy household with 60+ devices.

Approach: Diagnosed root cause (ISP modem bridge mode misconfiguration + channel congestion), then deployed a Ubiquiti UniFi stack with proper VLAN segmentation separating IoT, guest, and internal traffic. Documented topology, access control lists, and configuration baselines.

Outcome: Network outages reduced from ~50 per year to 1. Clean segmentation improved security posture and gave a documented baseline for future changes.
