Tracer FIRE Cybersecurity Incident Response Training

SIEM operations threat hunting log analysis KQL incident documentation forensics


Problem: Simulated post-breach environment requiring forensic investigation of attacker activity across a compromised SOC network.


Approach: Used Elastic SIEM for log correlation and Azure Data Explorer (ADX) for structured KQL-based queries to identify indicators of compromise and trace lateral movement. Supplemented with Velociraptor for endpoint forensics and Malcom for network graph analysis.


Outcome: Completed CTF-style incident response exercise with structured documentation of findings, attacker timelines, and control gap recommendations.
